# SA E-Commerce Data Engineering Pipeline

## Overview

A Python-based data engineering project focused on analysing
e-commerce sales, customer purchasing behaviour, and inventory
for a South African retail business scenario.

## Business Problems

- Identifying the most purchased products.
- Understanding customer purchasing patterns by age group.
- Analysing sales by province where data is available.
- Identifying low-stock and slow-moving products.
- Supporting data-driven inventory replenishment decisions.

## Technology Stack

- Python
- SQLite
- SQL
- HTTP APIs and REST
- Git and GitHub
- Automated testing

## Pipeline

Extract -> Validate -> Transform -> Load -> Analyse

## Data Sources

Public datasets and APIs will be documented as they are integrated.
Simulated data will be clearly labelled and separated from real data.
